# Five-member layout example

Synthetic preview based on Content Feed Reader, with three additional Experiences:
Compact library; Guided library for Readers who want a structured daily reading
routine; and Focused library, owned by the web Interface. These additions are
layout test data, not proposed teaching Blueprint behavior. They exercise five
members, long names, multi-paragraph conditions and different containers.
The two-member screenshots use the actual teaching Blueprint without additions.
