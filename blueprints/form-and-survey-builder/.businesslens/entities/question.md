# Question

One thing a form asks. Its answer type decides what a Respondent may give:
a short answer, a paragraph, one choice or several from listed options, a
rating, or a date.

## Information kept

- **Prompt** — the question as Respondents read it
- **Answer type** — the kind of answer it takes, with the options offered when it asks for a choice
- **Required** — whether a response must answer it whenever it is shown
- **Show condition** — an answer to an earlier choice question that must be given before this question is shown, if the Creator set one
