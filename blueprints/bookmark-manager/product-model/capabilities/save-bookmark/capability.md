# Bookmark saving

Keeps a page the Owner brings from the browser or from another app on their
phone as a bookmark, with the title the page gives itself unless the Owner
changes it, and an optional note, tags and collection.

## Intent

Make keeping a link a few seconds' work from wherever the Owner found it, so
that nothing worth finding again is lost for want of filing it first.
