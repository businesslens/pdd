# Suggestion preparation

Lets the Owner's AI agent read their bookmarks, collections and tags through
the agent connection and leave suggestions: a filing suggestion that puts
bookmarks into a collection, existing or new, with tags — for Unsorted
bookmarks and for what an import just added — and a duplicate suggestion for
bookmarks that lead to the same page. Leaving a suggestion changes nothing in
the library, and the Product refuses any direct change from the agent.

## Intent

Let an agent do the tedious part of tidying a library — reading every link and
noticing what belongs together — while every decision stays the Owner's.
