# Link creation

Creates an active link from a destination, with a slug the Product generates
or one the Owner chooses and an optional expiry — on the web, or through the
API by a tool holding one of the Owner's API keys.

## Intent

Make a short, unique, dependable address for any web destination in one step,
whether a person or their tool asks for it.
