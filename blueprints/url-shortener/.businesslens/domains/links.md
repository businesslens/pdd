# Links

The Owner's links: creating them, changing where they lead, disabling them,
letting them expire, finding them again, and reading how they were followed.

## Boundary

Owns links, their slugs, destinations, expiry and state, and the clicks they
receive. It does not own the API keys a tool creates links with, or the
redirect a Visitor meets when following a short address.
