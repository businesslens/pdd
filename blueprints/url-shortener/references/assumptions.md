# Shortener assumptions

These are assumptions to validate, not claims that research has proved them.

- Owners hand out short addresses in places they cannot edit later — print,
  slides, old posts — so they value a short address that never changes meaning
  over the ability to delete a link.
- Changing a link's destination is more useful to Owners than risky to
  Visitors, because the Owner is accountable for where it leads.
- A Visitor who meets a disabled, expired or unknown short address is better
  served by one neutral "unavailable" statement than by learning which it was.
- Owners judge a link by how often it is followed, when, and from which sites,
  countries and devices; they do not need to know who followed it.
- Click counts include every follow, automated ones among them; Owners accept
  that as long as the analytics say so.
- An Owner's tools mostly need to create links. Editing, disabling and reading
  analytics stay human decisions taken on the web.
- One API key per tool, shown once, is a familiar enough pattern that Owners
  copy the secret when it is created.

Future research may change the Product Model; this file does not override it.
