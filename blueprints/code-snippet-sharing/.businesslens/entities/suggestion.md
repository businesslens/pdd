# Suggestion

A title, description and tags the Snippet assistant proposes for the code a
Developer is writing, waiting for that Developer to accept or dismiss.

## Information kept

- **Suggested title** — the title the assistant proposes
- **Suggested description** — the description the assistant proposes
- **Suggested tags** — the tags the assistant proposes

## States

### Proposed

Shown beside the snippet's own fields. Nothing in the snippet has changed.

### Accepted

Its values have been placed in the snippet's fields, where the Developer can
still change them before saving.

### Dismissed

Set aside by the Developer. The snippet's fields are as they were.
