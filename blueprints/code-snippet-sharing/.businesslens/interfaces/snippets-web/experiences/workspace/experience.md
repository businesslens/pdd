# Developer workspace

The signed-in context in which a Developer writes, revises, shares and deletes
their own snippets, and reads and forks those other Developers made public.
Every snippet written here belongs to the signed-in Developer. The Snippet
assistant is present only in the editor, and only to propose details the
Developer asked for.
