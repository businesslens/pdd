# Snippets web application

The supported browser Interface for writing, sharing and finding snippets.
Reading a public or unlisted snippet and browsing public ones needs no account;
writing, revising, sharing and forking need a Developer session. The Snippet
assistant works inside the snippet editor, proposing details only when the
Developer there asks.
