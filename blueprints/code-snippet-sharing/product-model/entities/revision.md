# Revision

One saved version of a snippet's code. A snippet's revisions, newest first,
are its history; each can be opened at an address of its own.

## Information kept

- **Number** — its place in the snippet's history, counting from 1
- **Code** — the code as it was saved in this revision
- **Language** — the language the code was written in at this revision
- **Saved at** — when the owner saved it
