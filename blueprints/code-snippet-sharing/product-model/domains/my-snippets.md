# My snippets

The snippets a Developer owns: writing them with help describing them, revising
them, deciding who can read them, and deleting them.

## Boundary

Owns a snippet's details, code, revisions and visibility, and the details
suggested while it is written. It does not own how public snippets are found by
others or the copies other Developers fork from them.
