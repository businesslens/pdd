# A tag exists while a note carries it

A tag comes into being when it is first put on a note, and ends when it is
taken off the last note carrying it. No two of an Owner's tags share a name.

## Rationale

Tags are offered whenever the Owner tags a note or searches; a tag nothing carries
would only be noise in that list.
