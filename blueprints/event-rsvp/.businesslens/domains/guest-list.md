# Guest list

The host's view of who has answered an event, removing an answer that should
not be there, and the messages the host sends to the guests.

## Boundary

Owns how RSVPs are presented to the host, removing one, and the messages the
host sends. It does not own the RSVPs themselves, which guests give and change
and the waitlist moves, or the event's details.
