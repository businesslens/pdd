# Message

An email a Host sends to some or all of an event's guests, kept on the event so
the host can see what was said and to whom.

## Information kept

- **Subject** — what the email is about
- **Body** — what it says
- **Recipients** — the answers whose Guests it went to: going, maybe, waitlisted, or any of them together
- **Sent at** — when the host sent it
