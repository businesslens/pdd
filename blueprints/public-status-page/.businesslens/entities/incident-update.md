# Incident update

One entry on an incident's timeline: what the operators want visitors to know
at that moment. An update starts either as a draft the Drafting assistant
prepares or directly as the message an Operator posts.

## Information kept

- **Message** — the text visitors read
- **Notes** — the Operator's rough notes a draft was prepared from; never published
- **Incident status** — the incident status the update announces
- **Posted at** — when an Operator posted it

## States

### Draft

Prepared for an Operator to edit. Seen only in the operator console, and sent to
nobody.

### Posted

On the incident's public timeline, and emailed to confirmed subscriptions.
