# Component

One part of the service the page reports on, such as a website, an API or a
region, listed with the status visitors see.

## Information kept

- **Name** — what visitors know the component as, unique on the page
- **Description** — one line telling visitors what the component covers
- **Status** — what visitors see for it now: Operational, Degraded performance, Partial outage, Major outage or Under maintenance
