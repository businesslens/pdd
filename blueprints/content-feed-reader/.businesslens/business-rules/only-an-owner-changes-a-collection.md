# Only the owner changes a collection

A collection's contents, name, description, and visibility change only through
the reader who created it.

## Intent

A subscriber is watching someone's curation. If anyone else could change it, the
thing they subscribed to would not be that person's judgment any more.

## Rationale

Everyone else — subscribers, visitors, and readers who merely hold the link — has
read access and nothing more. Stating it as one rule keeps the same boundary from
having to be rediscovered separately on every surface a collection appears on.
