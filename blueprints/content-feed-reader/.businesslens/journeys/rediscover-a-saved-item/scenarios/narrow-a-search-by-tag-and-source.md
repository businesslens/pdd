# A reader narrows a search that returned too much

## Trigger

A search returns more matches than the reader can scan.

## Steps

1. The reader narrows the results by tag, by source, by read state, or by saved state
2. The result set updates to match
3. The narrowing stays visible so the reader can see why the results shrank and undo it

## Outcome

The reader reaches the item through a combination of a vague memory and a
confident one, and can always widen the search again.
