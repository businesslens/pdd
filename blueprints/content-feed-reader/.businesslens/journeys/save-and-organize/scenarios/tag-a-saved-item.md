# A reader files a saved item under tags

## Trigger

A reader adds one or more tags to a saved item, typing them freely.

## Steps

1. Tags that already exist in the reader's library are offered as the reader types
2. A tag that does not exist yet is created by using it
3. The tags are attached to the item
4. The item appears when browsing any of those tags

## Outcome

The item is filed under the reader's own vocabulary and is reachable by any of
its tags.

## Edge cases

- Tagging is available only on saved items, because the product may prune unsaved ones
- Removing the last item from a tag retires the tag from the reader's vocabulary
