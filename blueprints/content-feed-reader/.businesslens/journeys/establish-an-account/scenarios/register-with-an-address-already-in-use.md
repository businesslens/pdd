# Registration is refused for an address already in use

## Trigger

A visitor submits a registration form with an email address that already has an
account.

## Steps

1. The product finds an existing account for the address
2. Registration is refused
3. The visitor is shown a message offering to sign in instead, with the address carried across
4. The display name and any other entered detail are preserved

## Outcome

No second account exists for the address, no existing account is altered, and the
visitor is one action away from signing in.
