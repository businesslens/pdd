# Library search

Finds items, sources and collections across a Reader's whole library from one
entered term, and opens what was found. It is its own Capability because it
presents a set nothing else does: every kind of thing in the library at once.

## Intent

Let a Reader reach anything they remember by name without knowing which part
of the library holds it.
