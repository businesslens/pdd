# Reader mobile application

The supported mobile Interface for working in a Reader's private library:
following, refreshing, reading, saving and searching. It serves the library in
two versions at once, the classic one and the next one, and the search is
reachable from every place in either. Collection organization, publication,
and anonymous public collection links remain web commitments.
