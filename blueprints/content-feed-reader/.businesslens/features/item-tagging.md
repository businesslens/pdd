# Item tagging

Filing saved items under reader-defined tags, and browsing by tag.

## Intent

Tags are the reader's own vocabulary, invented as they go, so the product must
never require a tag to be defined before it is used. An item may carry several
tags because the reasons for keeping something rarely form a hierarchy.

Tags apply only to saved items. Tagging something the product may later prune
would quietly break the tag.
