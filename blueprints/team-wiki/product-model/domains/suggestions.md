# Suggestions

The updates Members' AI agents propose for stale or conflicting pages: an agent
leaving a suggestion for a space, and an Editor accepting or dismissing it.

## Boundary

Owns suggestions and their review. It does not own page content: a page changes
only through an Editor, and an accepted suggestion becomes an ordinary revision
in Pages. It does not own answering questions, which reads pages and keeps
nothing.
