# An Editor publishes every change an AI agent proposes

Nothing an AI agent proposes reaches a page until an Editor of the page's space
publishes it. Until then the page says what it said, every Member reads it as
it was, and the revision the Editor publishes names that Editor.

## Rationale

An agent can be wrong with confidence. Keeping a person between its proposal
and the page makes every change to the wiki one somebody chose.
