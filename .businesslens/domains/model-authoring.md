# Model authoring

Deciding what the Product Model should say and writing that decision down:
mapping behavior that already exists, deciding behavior that does not yet, and
resolving the gaps between the model and current repository behavior.

## Boundary

Owns product meaning and the approval that must precede writing it. It does not
own implementation, does not own the structural rules a written model must obey,
and never executes the repository it is describing.
