# Agent enablement

Getting the BusinessLens skills to where a coding agent will find them, and
keeping them current, without disturbing anything the Product does not own.

## Boundary

Owns skill distribution, the ownership marker that makes an installation
recognizable, installation scope, and the retirement of skills that no longer
ship. It does not own what those skills then decide, and it never creates or
touches a Product Model.
