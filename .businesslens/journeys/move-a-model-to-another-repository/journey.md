# Move a model to another repository

## Goal

A Product Model authored in one repository becomes the starting model in
another, carrying its product meaning and nothing that only made sense where it
came from.

## Success criterion

The receiving repository holds a structurally sound Product Model with the same
product meaning, no source-specific navigation, and an explicit note that
implementation alignment must be established there.

## Intent

This is the plain, offline half of Blueprint movement. Proposing a model to a
public catalog is a separate decision with a separate audience.
