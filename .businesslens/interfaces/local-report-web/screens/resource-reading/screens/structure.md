# Contained resources

An Interface's Experiences and Screens, or an Experience's own Screens and the
shared Screens it reaches, as the same expandable tree the Interfaces
collection draws. Group labels name the counted sets and empty groups are
omitted; a shared Screen is identified by its owning Interface with a link to
it. Chevrons expand and collapse, resource names open complete readings, and
expansion is retained across reading changes, related-resource lookups, refresh
and valid recompilation. Screens have no containment reading of their own.
