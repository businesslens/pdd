# Deep-dive rubric

- A journey is a stable goal, not a feature label or implementation unit.
- A scenario is a materially distinct observable path through that goal.
- Cover success, permission, validation, conflict, dependency failure, and
  recovery only when evidenced.
- Give every scenario its own direct evidence.
- Define experience access from actual guards: `public`, `authenticated`, or
  `restricted`.
- Keep uncertainty in limitations and avoid speculative completeness.
